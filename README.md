# Engineering Skills

Agent skills for software-engineering reviews, repository workflows, and
technical interview practice.

Thinking, productivity, learning, and writing skills live in
[`devinat1/skills`](https://github.com/devinat1/skills).

## Quickstart

Install individual skills with skills.sh:

```bash
npx skills@latest add devinat1/engineering-skills
```

To keep a local checkout inside the Claude folder and link every skill into
Claude Code and Codex:

```bash
git clone git@github.com:devinat1/engineering-skills.git ~/.claude/repos/engineering-skills
~/.claude/repos/engineering-skills/scripts/link-skills.sh
```
